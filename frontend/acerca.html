Ficha del proyecto

Software
TorqueStock — Sistema Web de Gestión de Almacén de Herramientas de Torque
Empresa
Grupo Industrial Par-Tec (proveedor automotriz Tier 2), Nuevo León
Propósito
Centralizar y automatizar el control del almacén de herramientas de torque para conocer en tiempo real la disponibilidad, el operador responsable de cada préstamo y la vigencia de calibración.
Normas
IATF 16949 · ISO 9001 · ISO 6789
Modelo de desarrollo
Incremental con prototipado evolutivo (3 incrementos)
Tecnología
Frontend: HTML5, CSS3 responsivo y JavaScript. Backend: servidor en Python con base de datos SQLite (usuarios, permisos, catálogos, inventario y bitácora) en la red local del almacén. Sin dependencias ni internet.
Fuera de alcance
Facturación, compras a proveedores, nómina y conexión con maquinaria CNC.
